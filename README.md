# 📱 DukaanPilot Android POS App

Official Android Application for **DukaanPilot - AI Smart Kirana POS & Billing OS**.

---

## 🌟 Key Features
- **100% Offline Capability**: Runs locally on your Android device with zero internet required.
- **Hardware Integration**:
  - 📷 Camera Barcode Scanner
  - 🎙️ Voice Billing (Hindi / English speech recognition)
  - 🔊 Smart 4G Soundbox Payment voice announcements
  - 🧾 WhatsApp digital receipt sharing
- **Phone-Friendly UI**: Optimized for one-hand cashier operations on smartphones & tablets.
- **Auto CI/CD**: Built automatically using GitHub Actions with downloadable APK releases.

---

## 🚀 How to Download the APK
1. Go to the **[Releases](https://github.com/Arjunrayhod/dukaanpilot-android/releases)** tab in this repository.
2. Download the latest **`app-debug.apk`**.
3. Install on your Android device (Enable *"Install unknown apps"* if prompted).
